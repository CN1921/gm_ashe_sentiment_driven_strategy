# Python / 掘金量化 / 市场情绪 / 事件驱动 / 风险控制

这是一个面向掘金平台的多因子量化交易策略仓库，核心目标是利用多个因子进行股票筛选和组合管理，帮助实现自动化交易策略。

## 1. 策略逻辑概述

多因子策略的核心思想是：不是依赖单一信号，而是同时观察多个维度的市场特征，把不同因子组合起来形成一个更稳定的决策信号。

常见因子包括：

- 估值因子：P/E、P/B、EV/EBITDA 等
- 动量因子：过去 3/6/12 个月收益率
- 质量因子：净利润增长率、ROE、毛利率
- 规模因子：市值大小、流动性
- 成长因子：营收增长、利润增长
- 技术因子：均线、RSI、MACD、成交量异常

策略通常按以下流程运行：

1. 获取候选股票池
2. 计算每个股票的多个因子值
3. 对各因子进行标准化处理
4. 汇总成多因子评分
5. 按得分排序，选出排名靠前的股票
6. 根据风控规则进行加权持仓
7. 定期重平衡，更新组合

## 2. 具体策略思路

一个典型的多因子策略，可以包含以下结构：

- 选股：在某个交易日，筛选出符合行业、流动性和估值要求的股票
- 因子打分：对每只股票计算多个因子得分
- 归一化：通过 z-score、分位数排序等方式标准化不同因子的量纲
- 组合评分：
  score = w1 * momentum + w2 * value + w3 * quality + w4 * volume + w5 * trend
- 选股排序：按 score 从高到低选择前 N 只股票
- 持仓管理：设定最大持仓、行业限制、单股敲入/敲出规则
- 风控：设置止损、止盈、回撤阈值

### 一个简单例子

```python
# 简化示例：多因子打分
score = 0.30 * momentum_score + 0.25 * quality_score + 0.20 * value_score + 0.15 * volume_score + 0.10 * trend_score
```

如果某只股票在多个正向因子上表现良好，则其综合评分会更高，策略会优先配置该股票。

## 3. 策略的关键逻辑模块

### 3.1 数据采集

从交易数据、财务数据、行情数据中获取必要信息，包括：

- 日线/分钟线行情
- 成交量、涨跌幅
- 财务指标
- 估值数据
- 周期收益率

### 3.2 因子计算

每个因子是一个评分规则，通常需要：

- 去极值
- 缺失值处理
- 分层排序或标准化
- 方向定义（高分代表好还是低分代表好）

### 3.3 组合与排名

所有股票的各项因子都计算完成后，采用加权方法合成总分，再按总分排序，选取优质股票。

### 3.4 交易执行

在交易日开盘前或收盘后，根据当前得分重建组合：

- 卖出分数低的股票
- 买入分数高的股票
- 控制仓位和换手率

### 3.5 风险控制

多因子策略虽然可以提高稳定性，但仍需控制：

- 单只股票最大权重
- 行业集中度
- 总体回撤
- 止损、止盈保护

## 7. 风险提示

量化策略不是“稳赚”，尤其是多因子策略在不同市场环境下会出现周期性失效。真正稳定的策略通常由以下几个部分共同构成：

- 数据清洗与异常处理
- 因子稳定性验证
- 组合分散与风险控制
- 交易成本控制
- 参数稳健性检查
